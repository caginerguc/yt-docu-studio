# Klasik müzik kütüphanesi

Renderer arka plan müziğini bu klasörden seçer (mp3, ogg, flac, wav, m4a, opus).

Buraya YALNIZCA kaydın kendisi şu lisanslardan biriyle işaretli dosyaları koy:
- Public Domain (CC + PD simgesi)
- CC0
- YouTube Ses Kitaplığı (YouTube Studio > Ses Kitaplığı) parçaları, yalnızca
  "Kullanım şartları: Atıf gerekli değil" filtresiyle indirilenler. Bunlar YouTube
  videolarında (para kazanılanlar dahil) atıfsız kullanılabilir.

İpuçları:
- GitHub sitesinden yüklenen dosya en fazla 25 MB olabilir (~10 dk altı parçalar).
- Aynı kaydı iki farklı adla ekleme: bir videoda art arda çalabilir.
- Belgesel tonuna uyan "Dramatik" / "Hüzünlü" parçaları seç; top atışlı, coşkulu
  finaller (ör. 1812 Uvertürü) anlatımla çatışabilir.

KOYMA:
- CC BY-NC (ticari kullanım yasak; reklam geliri olan kanal ticari sayılır)
- CC BY-NC-ND
- Lisansı belirtilmemiş her şey

CC BY (atıf gerekli) kayıtlar için ayrı klasör: assets/music/classical_by/
Dosya adı biçimi: Eser__Sanatçı.mp3  (atıf açıklamaya otomatik eklenecek)

Her indirdiğin parçanın lisans sayfasının ekran görüntüsünü sakla
(yanlış Content ID iddiasına itiraz için).
